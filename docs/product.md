# 产品需求与首版边界

## 已确认需求

- 产品名：兰谷多账号工具；仓库名：langu-account-tool。
- 使用对象：产品、运营、测试人员。
- 启动显示系统地址设置和主账号登录入口。
- 记住登录地址、用户名，并保持主账号的登录状态。
- 主账号打开原生内置浏览页面，正常使用系统登录流程。
- 移除顶部账号工作区横栏，主账号头像、username 和添加入口统一放在左侧。
- 左侧支持 68px 折叠栏：Logo、展开按钮、主/子账号，底部固定设置和关闭工作区按钮。
- 开发者工具使用扳手图标，位于首页按钮之后。
- 主账号必须在权限接口 result.auth 中具有 system:internalLoginByAdmin 授权，否则显示“暂无权限”并锁定工作区。
- 主账号过期后返回其登录页，禁止添加、重登或使用子账号；重新登录后恢复同一主账号的子账号列表。
- 每五分钟通过 SYSTEM_NOTIFICATIONS 配置接口进行主账号保活/有效性检测。
- 子账号支持左侧一键重新登录，主账号授权校验通过后才重新请求代登录接口。
- 使用主账号身份同步服务端允许访问的正常状态（status=1）用户，支持分页、增量同步和手动刷新。
- 左侧数据库图标进入用户列表，搜索图标进入独立搜索页面；均支持中文、拼音、账号、工号和部门检索。
- 每行右侧直接打开账号，无需二次确认；已打开的账号直接切换，其他账号经 internalLoginByAdmin 后打开独立页面。
- 使用原生标题栏支持 macOS 拖动、双击缩放和系统窗口按钮；右侧浏览器在工具栏下铺满，不保留底部状态栏。
- 左侧分别展示主账号和所有子账号，选中态和角色明确；切换保留页面状态。
- 子账号不设置业务数量上限，实际可打开数量受机器内存及 WebView 资源限制。
- 浏览工具包括地址、后退、前进、刷新、停止、首页、缩放及开发者工具。
- Windows、Linux、macOS 为产品目标，各架构按 docs/platforms.md 分阶段验证。

## 首版决策

- 每个工作区一次连接一套系统；关闭工作区后可切换登录/接口地址。
- 默认地址为 http://languwin.com/，接口为 http://api.languwin.com。
- 默认子账号跳转根路径 `/`，由原站路由决定登录信息页；设置项允许指定同源路径。
- 主账号依赖系统 WebView 持久化登录数据。不会保存密码或绕过原站验证码。
- 保持登录状态不能延长服务端 token 有效期；过期需重新登录。
- 子账号在本次运行保留，关闭会话或程序后不自动恢复子账号。
- 重复选择已打开用户会切换现有会话，不重复申请 token。
- 主账号过期或退出时隐藏并锁定子账号，不丢弃列表；切换为不同主账号或租户时销毁原子账号。
- 弹窗期间隐藏原生账号 WebView，避免原生视图遮盖 Vue 弹窗。
- 新窗口链接在当前账号页打开，保持其账号身份；暂不做每账号多标签或弹出式窗口管理。
- 上传、下载和右键菜单依赖系统 WebView；这不是带 Chrome 扩展生态的完整浏览器。
