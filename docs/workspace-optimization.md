# 工作区优化设计（2026-10-14）

根据确认方案实施，范围包含账号切换提示、本地用户目录与搜索、原生菜单/托盘/关闭隐藏、本地开发打包脚本。

- 切换提示使用父窗口所属的透明、不激活、鼠标穿透窗口；只显示姓名、账号、部门，不向提示窗口授予 Tauri capability。只在选择发生变化后显示，弹窗期间延迟至业务页恢复。文字模糊淡入淡出，减少动画设置下关闭动效。
- Rust 在 SQLite 中持久化身份字段白名单，按登录地址、接口地址、租户及主账号身份分区。前端只获得检索页与同步摘要。每账号的业务 WebView/profile 保持独立。
- 主账号权限校验后后台首次全量；进程重启或主账号重新登录后补拉创建时间和更新时间，使用服务器时钟与两分钟重叠窗口，ID 去重合并。手动刷新、距上次校准一天执行全量。整批成功才提交事务和游标；失败保留旧快照。主账号变化时旧任务结果失效。
- 普通列表接口没有删除变化流，部门字典修改和权限范围改变也不一定改变用户更新时间，因此以全量校准修正。缓存仅用于检索，代登录仍由服务端鉴权。
- 本地检索支持姓名、账号、工号、实际部门、拼音全拼及首字母、多关键词、键盘选择。部门取 realDepart_dictText，避免把权限部门 orgCodeTxt 当成实际部门。保留常见多音姓氏别名；未承诺任意中文读音的语义匹配。
- 参考 nacos-control-panel 的原生菜单、托盘、标题栏布局；关闭窗口隐藏，菜单退出才结束进程。界面事件仅发给本地主 shell，所有自定义 command 继续验证来源。
- 本地脚本使用 Node 标准库启动 Tauri，校验宿主操作系统和目标标准库，开发 profile 独立，打包后另存中文文件名。Mac Intel/ARM 独立；Windows/Linux 依赖对应宿主工具链。

验收：分页完整、重启增量、更新时间为空的新用户、手动移除删除用户、失败不推进游标、跨身份隔离、拼音/部门检索、原生提示不抢焦点、隐藏恢复保留页面草稿，以及现有主子账号隔离回归。
